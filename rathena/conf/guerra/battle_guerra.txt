//--------------------------------------------------------------
// Teto da reducao de dano por carta, em MILESIMOS.
//
// Esta opcao NAO existe no rAthena - e nossa, definida em

// src/custom/reducao_de_dano.hpp. Alterar aqui exige
// `@reloadbattleconf`, nao recompilar.
//
// O rAthena grampeia a reducao em `max(0, ...)`: somando 100% de
// resistencia, o dano vira ZERO. Em 2026-08-09 um Sura de guerra

// ATENCAO: o teto vale para a reducao de carta INTEIRA, nao so
// para a de raca - elemento, tamanho, classe e distancia entram na
// mesma conta. E de proposito: a regra e "nada e imune". Quem for
// calibrar resistencia a elemento precisa saber disso.
//
// Nao alcanca o que ja escapava da reducao de carta por outros
// motivos - habilidade com IgnoreDefCard, dano fixo, reflexo, dano
// de status. A lista esta em REDUCAO-DE-DANO.md.

//--------------------------------------------------------------

// Pedido em 2026-08-10. Comecou em 70%, que era como o bRO estava

//
// OS DEZ FICAM NO MESMO NUMERO, POR PEDIDO EXPLICITO: "nao quero
// diferenciar habilidades de ataque". A separacao em cinco por
// ambiente e do rAthena - habilidade reduz por TIPO (arma, magia,
